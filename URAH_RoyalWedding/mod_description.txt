AI disclosure: this mod was made with the help of AI (Claude, by Anthropic).

An unmarried king can hold a royal wedding feast to find a bride among the noble ladies of his own
court: the button sits in the empty spouse slot of the royal family window. The feast costs gold
(more for a bigger kingdom), takes 90 seconds and succeeds by chance: base 20%, plus the king's level,
knights at court and the king effects of Courtesy (+10/20/30%) and Rhetoric
(+5/10/15%, shown in the skill tooltips), minus old age and war. A failed feast keeps its gold and
the next one has to wait 5 minutes. The bride is the same as the game's own random local marriage.

Requires BepInEx 5 and the URAH_Loader plugin installed.
Or you can just install the URAH_Starter package, it ships both:
(unzip into the game folder, see INSTALL.md inside):
https://github.com/URAHDangerzone/URAH_koh2_releases/releases
Without it this mod does nothing.

Multiplayer: host and guests need mod and loader;
the feast only shows for guests while the host runs the plugin.

WARNING: this mod contains program code. Its plugins/ folder holds a DLL (URAH_RoyalWedding.dll)
that runs inside the game with the full rights of your Windows user, like any program you start.
URAH_Loader only loads it when it carries the URAH release signature, so a file changed by anyone
else is refused. It is built and signed by GitHub Actions from the public source below; the GitHub
release lists the SHA-256 of every file.
